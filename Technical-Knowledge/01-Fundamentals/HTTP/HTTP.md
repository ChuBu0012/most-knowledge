# HTTP

## Overview

พื้นฐานโปรโตคอล request/response ที่ใช้สื่อสารระหว่าง client และ server บนเว็บ

## แนวคิดหลัก

HTTP message, methods, status codes, headers, caching, TLS และ semantics ของ safe/idempotent methods. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
