# State Management Concepts

## Overview

หลักการกำหนดเจ้าของและวงจรชีวิตของ state ใน application เพื่อหลีกเลี่ยงการ sync ซ้ำซ้อน

## แนวคิดหลัก

แยก local UI state, shared client state, URL state และ server state; เลือกตำแหน่งเก็บใกล้ผู้ใช้ข้อมูลที่สุด. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
