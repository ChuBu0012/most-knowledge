# OpenAPI

## Overview

มาตรฐานคำอธิบาย HTTP API ที่เครื่องมือใช้สร้าง docs, clients และ validation

## แนวคิดหลัก

paths, operations, schemas, security schemes และ versioning ของ API contract. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
