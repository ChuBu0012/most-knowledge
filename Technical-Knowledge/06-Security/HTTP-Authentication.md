# HTTP Authentication

## Overview

กลไกยืนยันตัวตนระดับ HTTP เช่น Basic/Bearer challenge และ authentication headers

## แนวคิดหลัก

แยก authentication จาก authorization; ใช้ TLS, ปกป้อง credentials และเลือก scheme ตาม threat model. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
