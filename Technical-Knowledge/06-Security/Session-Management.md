# Session Management

## Overview

วิธีรักษาสถานะผู้ใช้ข้าม HTTP requests โดยใช้ session identifier และ server-side state

## แนวคิดหลัก

cookie flags, rotation, expiration, CSRF protection, revocation และ distributed storage. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
