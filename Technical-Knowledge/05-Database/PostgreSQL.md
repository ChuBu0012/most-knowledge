# PostgreSQL

## Overview

relational database ที่รองรับ SQL, transactions, constraints และ extensible data types

## แนวคิดหลัก

schema design, indexes, transactions, isolation และ query planning. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
