# Python

## Overview

ภาษาโปรแกรม general-purpose ที่อ่านง่ายและมี ecosystem สำหรับ API, automation และ data work

## แนวคิดหลัก

syntax, virtual environments, packages, type hints และ async programming. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
