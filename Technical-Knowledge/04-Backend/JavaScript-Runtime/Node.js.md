# Node.js

## Overview

JavaScript runtime ฝั่ง server ที่สร้างบน V8 และ event loop พร้อม APIs สำหรับ I/O

## แนวคิดหลัก

event loop, non-blocking I/O, module system, package ecosystem และ process lifecycle. อ่านแนวทางและรายละเอียด version/runtime จากมาตรฐานหรือเอกสารทางการก่อนนำไปใช้จริง

## เริ่มเรียนอย่างไร

1. เข้าใจคำศัพท์และ model พื้นฐานจากเอกสารอ้างอิง
2. ทดลองตัวอย่างขนาดเล็กและสังเกตผลลัพธ์/error
3. เพิ่มเรื่อง security, performance และ production เมื่อโจทย์ต้องใช้
