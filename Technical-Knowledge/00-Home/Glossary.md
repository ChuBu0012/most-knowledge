# Glossary

| คำ | ความหมายสั้น ๆ |
|---|---|
| API | สัญญาการเรียกใช้ความสามารถระหว่างซอฟต์แวร์ |
| SSR | สร้าง HTML บน server ก่อนส่งให้ browser |
| SSG | สร้างหน้า HTML ล่วงหน้าตอน build |
| Runtime | สภาพแวดล้อมที่รันโปรแกรม เช่น Bun หรือ Go runtime |
| ORM | abstraction ที่ map ข้อมูลระหว่าง object กับ relational database |
| Server state | ข้อมูลที่มีแหล่งจริงอยู่บน server และต้อง sync/cache ฝั่ง client |
| Client state | state ที่แอปเป็นเจ้าของ เช่นเปิด dialog หรือ draft ที่ยังไม่บันทึก |
| Headless UI | logic/behavior โดยไม่บังคับ markup หรือ visual style |
| Middleware | ขั้นประมวลผลที่แทรกระหว่าง request กับ handler |
| Migration | การเปลี่ยน schema/data แบบมีประวัติและทำซ้ำได้ |
| JWT | รูปแบบ compact claims; ไม่ใช่กลไก authentication โดยตัวมันเอง |
| OAuth 2.0 | กรอบมอบ authorization ให้ client เข้าถึง resource |
| Virtualization | render เฉพาะรายการที่มองเห็นเพื่อลด DOM |
| E2E test | ทดสอบ journey ผ่านระบบที่ประกอบใกล้เคียงการใช้งานจริง |
