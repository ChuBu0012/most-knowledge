# Linux Simple Guide: คู่มือคำสั่ง Linux ฉบับกระชับ เข้าใจง่าย (ใช้จริงทันที)

หากไฟล์ [[LINUX-CHEATSHEET]] ยาวเกินไปและมีเนื้อหาทางเทคนิคมากเกินความจำเป็น หน้านี้สรุป **คำสั่ง Linux ที่นักพัฒนาและวิศวกรระบบใช้บ่อยที่สุด 15-20 คำสั่ง** จัดหมวดหมู่ตามการใช้งานจริง พร้อมคำอธิบายภาษาพูดที่เข้าใจได้ทันที

---

## 🧭 1. เดินสำรวจและจัดการไฟล์ (Navigation & Files)

คิดภาพเหมือนการเปิด File Explorer / Finder แต่เปลี่ยนมาพิมพ์ข้อความแทน:

| คำสั่ง | ตัวอย่างการใช้ | ความหมาย |
| :--- | :--- | :--- |
| `pwd` | `pwd` | ดูว่าตอนนี้เรายืนอยู่ที่โฟลเดอร์ไหน (Print Working Directory) |
| `ls` | `ls -la` | ดูรายชื่อไฟล์ทั้งหมด (รวมไฟล์ซ่อน และแสดงขนาด/สิทธิ์) |
| `cd` | `cd my-project` | เปลี่ยนโฟลเดอร์เข้าไปข้างใน |
| `cd ..` | `cd ..` | ถอยหลังกลับมาโฟลเดอร์ก่อนหน้า 1 ชั้น |
| `mkdir` | `mkdir -p src/components` | สร้างโฟลเดอร์ใหม่ (ใส่ `-p` เพื่อสร้างโฟลเดอร์ย่อยพร้อมกันได้) |
| `touch` | `touch app.js` | สร้างไฟล์เปล่าใหม่ทันที |
| `cp` | `cp file.txt backup.txt` | คัดลอก (Copy) ไฟล์ (ถ้าก็อปโฟลเดอร์ใช้ `cp -r`) |
| `mv` | `mv old.txt new.txt` | ย้ายไฟล์ หรือใช้เปลี่ยนชื่อไฟล์ |
| `rm` | `rm file.txt` | ลบไฟล์ |
| `rm -rf` | `rm -rf folder_name` | ⚠️ ลบทั้งโฟลเดอร์และของข้างในทิ้งทันที (ใช้ด้วยความระมัดระวัง) |

## 🔍 2. ค้นหาและเปิดดูเนื้อหาในไฟล์ (Search & Inspect)

| คำสั่ง | ตัวอย่างการใช้ | ประโยชน์ |
| :--- | :--- | :--- |
| `cat` | `cat config.json` | ปริ้นเนื้อหาทั้งหมดในไฟล์ออกมาดูบนหน้าจอ |
| `head` / `tail` | `tail -n 20 error.log` | ดู 20 บรรทัดแรก (`head`) หรือ 20 บรรทัดท้าย (`tail`) |
| `tail -f` | `tail -f access.log` | ⭐️ ดู Log สดแบบเรียลไทม์ (เมื่อมีบรรทัดใหม่จะเด้งขึ้นมาทันที) |
| `grep` | `grep -r "API_KEY" .` | ⭐️ ค้นหาคำที่ต้องการ ในทุกไฟล์ของโฟลเดอร์ปัจจุบัน |
| `find` | `find . -name "*.js"` | ค้นหาตำแหน่งไฟล์ตามชื่อ |

## ⚙️ 3. ตรวจสุขภาพเครื่องและโปรเซส (System & Processes)

| คำสั่ง | ตัวอย่างการใช้ | ประโยชน์ |
| :--- | :--- | :--- |
| `df -h` | `df -h` | เช็กพื้นที่ฮาร์ดดิสก์ที่เหลืออยู่ (อ่านง่ายในหน่วย GB/MB) |
| `free -m` | `free -m` | เช็ก Memory (RAM) ที่เหลืออยู่ |
| `ps aux` | `ps aux \| grep node` | ดูว่ามีโปรแกรมอะไรกำลังทำงานอยู่บ้าง |
| `kill` | `kill -9 <PID>` | สั่งปิดหรือดับเบิ้ลคลิกบังคับหยุดโปรแกรมตามหมายเลข PID |
| `top` / `htop` | `top` | เปิด Task Manager แบบ Terminal สดๆ (กด `q` เพื่อออก) |

## 🌐 4. เน็ตเวิร์กและการเชื่อมต่อ (Network & Download)

| คำสั่ง | ตัวอย่างการใช้ | ประโยชน์ |
| :--- | :--- | :--- |
| `curl` | `curl -I https://example.com` | ยิงทดสอบดู Response Header ของเว็บหรือ API |
| `ping` | `ping -c 4 8.8.8.8` | ทดสอบความเร็วและความเสถียรของการเชื่อมต่อไปยังปลายทาง |
| `ssh` | `ssh user@192.168.1.50` | รีโมตล็อกอินเข้าไปทำงานบนเซิร์ฟเวอร์ปลายทาง |

## 💡 5. คีย์ลัดใน Terminal ที่ช่วยประหยัดเวลา 10 เท่า

1. **กดปุ่ม `Tab` สองครั้ง:** ช่วยเติมชื่อไฟล์หรือโฟลเดอร์ให้อัตโนมัติ (ไม่ต้องพิมพ์เองทั้งหมด)
2. **กด `Ctrl + C`:** บังคับหยุดคำสั่งที่กำลังรันอยู่ค้างเติ่งทันที
3. **กด `Ctrl + R`:** เสิร์ชประวัติคำสั่งเก่าๆ ที่เราเคยพิมพ์ไปแล้ว
4. **กด `Ctrl + L` (หรือพิมพ์ `clear`):** ล้างหน้าจอ Terminal ให้สะอาดตา
5. **ลูกศร `ขึ้น ⬆` และ `ลง ⬇`:** เลื่อนดูคำสั่งล่าสุดที่เพิ่งพิมพ์ไป
